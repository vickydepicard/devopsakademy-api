# DevOpsAkademy API

Production-ready REST API built with **Node.js, TypeScript and Express**.

This backend is designed with a **DevOps & DevSecOps mindset**:
tests, documentation, security and CI/CD readiness are first-class citizens.

- REST API with Express & TypeScript
- JWT Authentication & role-based access
- Automated tests (Jest & Supertest)
- Swagger / OpenAPI documentation
- Centralized error handling
- Security-first architecture
- CI/CD ready (GitHub Actions)
